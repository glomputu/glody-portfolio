# Audit des réalisations

Audit effectué le 26 août 2026 avant intégration dans le portfolio. Ce document conserve les éléments de provenance qui ne sont pas destinés à l’interface publique.

## DNK-SYSTEMS

- Source : `https://github.com/glomputu/DNK-SYSTEMS`
- Visibilité constatée : dépôt accessible avec les identifiants Git locaux, mais inaccessible anonymement.
- Historique : un commit daté du 2 juillet 2026, signé « glody mputu » avec l’adresse du propriétaire du portfolio.
- Stack réellement utilisée dans le code : React, TypeScript, Vite, Tailwind CSS, Motion et Web Storage.
- Modules constatés : gestion immobilière, pisciculture, écloserie, stocks, comptabilité, portail client, utilisateurs, rôles, permissions, validation et audit.
- Limite publique : la version auditée stocke ses données de démonstration dans le navigateur. Les dépendances Google GenAI et Express sont déclarées mais aucune utilisation n’a été trouvée dans le code applicatif ; elles ne sont donc pas présentées comme technologies du projet.
- Visuels : l’application a été lancée localement. Les vues contiennent des données de démonstration et des images de tiers ; aucune capture n’est publiée automatiquement.

## FPF RDC

- Source : `https://github.com/adonaiKasawa/fpf_rdc`
- Contexte confirmé : Front des Professeurs Français à Kinshasa.
- Visibilité constatée : dépôt accessible avec les identifiants Git locaux, mais inaccessible anonymement.
- Historique : 17 commits entre septembre et octobre 2022, avec plusieurs contributeurs.
- Contribution GloDi MPUTU : le commit `400535e` ajoute le contrôleur, le modèle, les vues, le JavaScript et les tables du module de comptabilité. Le commit `729eb0f` est un merge et n’est pas utilisé pour attribuer d’autres modules.
- Fonctions attribuables : caisses, recettes, dépenses, soldes, journal de caisse et génération de bons associés.
- Stack constatée : PHP, MySQL, JavaScript, jQuery et Bootstrap.
- Autres fonctions de la plateforme : publications, rédaction collaborative, ressources, réunions, planification, sondages et gestion des utilisateurs.
- Visuels : aucun dossier de captures identifiable. Les documents téléversés dans le dépôt ne sont pas réutilisés afin d’éviter de publier des données appartenant à l’organisation.
